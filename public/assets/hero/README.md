# Homepage slider images

All images are AI-generated illustrative education scenes, not photographs of
real G WORLD students, staff or facilities. Optimized WebP files are hosted
locally, with no external image service or article API required.

| Slide | Foreground photo | Separate gradient-backed background |
| --- | --- | --- |
| Courses | `learning-library.webp` — students studying | `library-background.webp` — university library interior |
| Tech Skills | `digital-classroom.webp` — collaborative learning | `lab-background.webp` — computer laboratory |
| JAMB | `exam-preparation.webp` — a learner revising | `campus-background.webp` — university campus courtyard |

The three background files are distinct from all three foreground photos.
Every loop retains these pairings. Source PNGs are excluded; local images are
compressed to a maximum width of 1600 pixels.
